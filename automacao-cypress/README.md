# Automação de Testes com Cypress

## Objetivo
Praticar a automação de testes funcionais em aplicações web.

## Cenários de teste
- Validar login com credenciais válidas.
- Validar login com credenciais inválidas.
- Verificar o redirecionamento após o login.

## Tecnologias em estudo
- Cypress
- JavaScript
- Node.js
- Git e GitHub

## Status
Projeto em desenvolvimento. Estou aprendendo automação de testes e praticando os conceitos estudados.
