# Testes Manuais

## Objetivo
Praticar testes funcionais em aplicações web, verificando se as funcionalidades atendem aos resultados esperados.

## Atividades
- Elaboração de casos de teste.
- Execução de cenários de teste.
- Comparação entre resultados esperados e encontrados.
- Registro de evidências.
- Documentação de possíveis defeitos.

## Ferramentas
- Google Sheets
- Navegador web

## Aprendizados
Este projeto reúne práticas de teste manual e documentação de resultados, desenvolvidas durante meus estudos em QA.
